# גישה מרחוק למחשב וענן תמונות פרטי

[English README](README.md) · [תרשים המערכת](docs/architecture.mmd) · [הוראות תפעול](docs/OPERATIONS.md)

הפרויקט מחבר בין שלוש יכולות:

1. **שליטה מרחוק:** Mac → Tailscale → חיבור RDP למחשב Windows, גם כשהמחשבים מחוברים לרשתות שונות.
2. **הדלקה מרחוק:** Mac → SSH מאובטח דרך Tailscale → טלפון Android ישן עם Termux → Wake-on-LAN למחשב הנייח ברשת הביתית.
3. **שרת תמונות פרטי:** Immich פועל ב-Windows באמצעות Docker. התמונות והסרטונים נשמרים בכונן NTFS חיצוני, ומסד הנתונים נמצא ב-Docker Volume נפרד על האחסון הפנימי. Tailscale Serve מספק כתובת HTTPS פרטית ל-Mac ולאייפון.

## סטטוס

**עובד ואומת:** חיבור RDP מרחוק, הדלקת מחשב דרך Android, שרת Immich, שמירת תמונת ניסיון בכונן הייעודי, גישה מאובטחת ב-HTTPS, צפייה בתמונות באייפון ובדיקת חיבור ImmiBridge.

**עדיין לא הופעל:** גיבוי מלא או מתוזמן מספריית Apple Photos ב-Mac. יש לחבר את הכונן החיצוני שבו נמצאת הספרייה, לוודא שהיא הספרייה הפעילה ולבצע Dry Run לפני גיבוי ראשון.

## מה יש בתיקייה?

- `scripts/mac/` — הדלקת המחשב דרך SSH ובדיקות זמינות ותקינות מקור התמונות.
- `scripts/termux/` — שליחת חבילת WoL מטלפון ה-Android ברשת המקומית.
- `scripts/windows/` — פקודות לתפעול Immich ולפתיחת HTTPS באמצעות Tailscale Serve.
- `immich/.env.example` ו-`config/` — דוגמאות בלבד, ללא פרטים אמיתיים.
- `docs/*.mmd` — תרשימי Mermaid שאפשר להציג או לערוך ב-GitHub.
- `docs/OPERATIONS.md` — הוראות שימוש ופתרון בעיות.
- `docs/SECURITY.md` — אמצעי אבטחה והגבלות.
- `tests/` ו-`tools/` — בדיקות קוד וסריקת מידע רגיש לפני פרסום.

## פרטיות ופרסום

אין במאגר כתובות אישיות, שמות מחשבים אמיתיים, כתובות דוא״ל, סיסמאות, מפתחות API, מפתחות SSH, כתובות MAC או נתיבי ספרייה פרטיים. **אין להעלות את הקבצים המקומיים `.env`, `*.env.local`, קובצי מפתחות או ספריות תמונות.**

בדיקה לפני העלאה ל-GitHub:

```bash
python3 -m unittest discover -s tests -v
python3 tools/check_public_repo.py
```

## התחלה מהירה

הפקודות המלאות וקובצי ההגדרות מפורטים ב-[README באנגלית](README.md) וב-[OPERATIONS](docs/OPERATIONS.md). אין להריץ סקריפטים לפני התאמת קובצי הדוגמה למחשבים שלך **באופן מקומי**.

להצגת תרשים Mermaid יש להיכנס לקובץ `.mmd` ב-GitHub או להעתיק את התוכן ל-Mermaid Live Editor. התרשים המרכזי מופיע גם בתוך README באנגלית.
